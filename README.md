# hard-maze-maker — 世界一難しい迷路

人間が迷路を解くときの定番戦略を **体系的に無効化** して「難しさ」を最大化する迷路ジェネレータです。
ブラウザだけで遊べる [`index.html`](index.html) と、画像・データを吐く [`maze.py`](maze.py) が入っています。

![sample](examples/sample.svg)

## なにが「難しい」のか

普通の迷路は、次のどれかの戦略でわりと簡単に解けてしまいます。この迷路は
それを一つずつ潰しにいきます。

| 定番の攻略法 | 無効化する仕組み |
| --- | --- |
| **壁伝い法（右手/左手法）** | 行き止まりを繋いで **ループ（braid）** を作り、単純連結グラフを崩す。壁を辿ると同じ場所をぐるぐる回り続ける。 |
| **行き止まり潰し法** | 同じ braid によりループができるため、行き止まりを塗り潰しても道が閉じない。 |
| **なんとなく最短で進む直感** | recursive backtracker で通路を長く蛇行させ、**グラフ直径の両端**を入口・出口に置いて最短解を最長化。 |
| **一発運ゲー** | 候補を複数生成し、**難易度スコア最大の一枚を選抜**。 |

## 難易度スコア

各迷路を BFS で解析し、次の指標を合成します。

- `solution_len` — 最短解の長さ（長いほど難しい）
- `decisions` — 分岐点（次数 3 以上のセル）の数＝迷いやすさ
- `loops` — 独立ループ数（循環ランク `edges − cells + 1`）＝壁伝い法を破る指標
- `tortuosity` — 解経路の曲がり率（くねり具合）

```
score = solution_len + 0.8·decisions + 2·loops + 0.5·tortuosity·solution_len
```

## ブラウザで遊ぶ

[`index.html`](index.html) をブラウザで開くだけ。ビルド不要・依存なしの単一ファイルです。

- 移動: 矢印キー / `WASD` / `hjkl` / 画面下のパッド / スワイプ
- サイズ（15〜41）、意地悪さ（ループ量）、選抜数を切り替え可能
- `ヒント` で最短解を表示（ズル）／タイム・歩数・効率を計測

## コマンドラインで生成する

```bash
# ASCII で表示
python3 maze.py --width 31 --height 31 --candidates 40 --seed 42

# 解つき SVG を書き出す
python3 maze.py --width 25 --height 25 --candidates 40 --render svg --out maze.svg --show-path
```

主なオプション:

| オプション | 意味 | 既定値 |
| --- | --- | --- |
| `--width` / `--height` | 迷路のセル数 | 31 |
| `--candidates` | 生成して比較する候補数（多いほど難しい一枚を選抜） | 30 |
| `--braid` | 行き止まりをループ化する割合 0〜1 | 0.35 |
| `--seed` | 乱数シード（再現用） | ランダム |
| `--render` | `ascii` / `svg` / `none` | ascii |
| `--show-path` | SVG に最短解を重ねる | off |

依存ライブラリはありません（標準ライブラリのみ）。

## 仕組み（生成アルゴリズム）

1. **recursive backtracker** で完全迷路（穴なし・ループなし）を掘る。深さ優先で
   掘るため通路が長く蛇行し、解が伸びやすい。
2. **braid** で行き止まりを確率的に隣へ接続してループを作る。これで壁伝い法・
   行き止まり潰し法が破綻する。
3. **BFS を 3 回** 回してグラフ直径を求め、その両端を入口・出口に設定して最短解を最長化。
4. 1〜3 を候補数だけ繰り返し、難易度スコア最大の迷路を選抜。
